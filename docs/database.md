# Database (PostgreSQL, managed by Spring Boot + Flyway)

Owner of this design: C0. Implementation (`backend/src/main/resources/db/migration`): W2.
All timestamps are `timestamptz` stored in UTC. Primary keys are UUIDs generated by the app.
No images, video, face crops, landmarks or embeddings are stored anywhere.

### activity_intervals
| column | type | notes |
|---|---|---|
| id | uuid PK | |
| session_id | uuid FK study_sessions | |
| student_id | uuid FK users | denormalized for overlap constraint and queries |
| state | varchar(32) | ActivityState |
| reason | varchar(32) | TransitionReason that opened it |
| started_at | timestamptz | |
| ended_at | timestamptz null | null = open |
| opened_by_event_id | uuid FK monitoring_events null | |
| created_at | timestamptz | |
- partial UNIQUE (`session_id`) WHERE `ended_at IS NULL` — one open interval per session.
- CHECK (`ended_at IS NULL OR ended_at > started_at`).
- `EXCLUDE USING gist (student_id WITH =, tstzrange(started_at, COALESCE(ended_at, 'infinity'), '[)') WITH &&)`
  (requires `CREATE EXTENSION IF NOT EXISTS btree_gist`) — intervals of a student never overlap,
  including across session restarts.
- index (`student_id`, `started_at`).
