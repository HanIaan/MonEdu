# 실제 Safari 수동 테스트 체크리스트

Playwright WebKit 자동 테스트는 **Safari가 아닙니다.** WebKit 엔진만 같고 Safari 앱의 전력 절약,
자동재생 정책, 탭 일시정지, 카메라 권한 UI, macOS 카메라 표시등은 재현하지 않습니다.
아래 항목은 사용자가 실제 Safari.app과 실제 웹캠으로 직접 확인해야 합니다.

## 준비
- macOS Safari (버전 기록: Safari ▸ Safari에 관하여)
- 서버 실행: README의 "실행 방법" (프론트 http://localhost:3000, 백엔드 8080)
- 진단 페이지: `cd tests/e2e/fixtures && python3 -m http.server 4800` → http://localhost:4800/video-visibility-probe.html
- 계정: 학생 `student3@demo.local`, 선생님 `teacher2@demo.local` (비밀번호 `demo1234!`).
  자동 테스트가 쓰는 student1/student2는 사용하지 마세요. 세션이 서로 교체됩니다.
