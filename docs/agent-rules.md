## Hard rules

1. **Contract first.** `docs/contracts/openapi.yaml`, `docs/contracts/state-machine.md`,
   `docs/contracts/monitoring-events.md`, `docs/database.md` and
   `frontend/src/features/monitoring/contracts.ts` are binding. Do not invent new endpoints, fields,
   enum values or response shapes. Need a change? Stop and emit a `CONTRACT_CHANGE_REQUEST`
   (format below) in your final report; do not edit the contract yourself.
2. **Stay in your paths.** Never edit files owned by another agent. Shared files
   (`package.json`, lockfiles, tsconfig, eslint/vitest/next config, `.env.example`) are C0's —
   request changes instead. Never run `npm install <pkg>` (it rewrites shared files); `npm ci` is fine.
3. **Git.** Commit only on your own branch, in your own worktree. Never merge to `main`, never
   force-push, never touch other agents' branches/worktrees. No `git push` unless C0 asks.
   Never use bare `git stash`.
4. **Privacy.** No raw video, frames, images, face crops, landmarks, bounding boxes or embeddings may
   leave the browser or be stored. Only the JSON in the OpenAPI contract is sent.
5. **Secrets.** Never commit secrets. Config comes from environment variables (see `.env.example`).
   Never print API keys.
6. **Honesty.** Do not claim a capability (e.g. "detects phone use") you have not verified. Phone
   detection = *suspicion*; focus = *estimate*. Report failing tests as failing.
7. **Time.** Store/transmit UTC ISO-8601. Display Asia/Seoul. Measure durations by elapsed time,
   never by counting timer ticks.

## Commands

```bash
# frontend (Node >= 20.9)
cd frontend && npm ci
npm run typecheck && npm run lint && npm test        # vitest
npm run dev                                          # http://localhost:3000

# backend (Java 21)
export JAVA_HOME=$(/usr/libexec/java_home -v 21)
cd backend && ./gradlew test                         # JUnit + Testcontainers (needs Docker)
./gradlew bootRun                                    # http://localhost:8080 (needs DB, see infra)

# infra
docker compose -f infra/docker-compose.yml up -d postgres
```

## Report envelopes (end your final message with exactly one)

```
SUPERSET_WORKER_DONE
agent: <W1|W2|W3>
task: <task-id>
summary: <one line>
changed_files: <comma-separated paths>
tests_run: <commands>
test_results: <pass/fail counts, verbatim key lines>
commit_hash: <full sha on your branch>
remaining_issues: <list or none>
```

```
SUPERSET_WORKER_BLOCKED
agent: <W1|W2|W3>
task: <task-id>
blocker: <specific>
required_action: <what C0 / the user must do>
```

```
CONTRACT_CHANGE_REQUEST
agent: <id>
file: <contract file>
change: <exact proposed change>
reason: <why>
```
