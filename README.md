# Study Monitor

Webcam-based study monitoring (attendance at 09:00 KST, seating, focus *estimate*, phone-use
*suspicion*, away, end of study). All video analysis runs **in the student's browser**
(MediaPipe Tasks Vision); only state-transition JSON reaches the Spring Boot backend.

> Work in progress — full run guide is written at integration (C0). See `AGENTS.md` and `docs/`.
